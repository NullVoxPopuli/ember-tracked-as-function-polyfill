# How To Contribute

## Installation

- `git clone <repository-url>`
- `cd ember-tracked-as-function-polyfill`
- `pnpm install`

## Linting

- `pnpm lint`
- `pnpm lint:fix`

## Building the addon

- `pnpm build`

## Running tests

- `pnpm test` runs the babel plugin tests.
- The Ember tests are in the test apps. From the repository root, `pnpm test` runs all of them.
